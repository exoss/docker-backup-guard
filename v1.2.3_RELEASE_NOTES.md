# Release Notes v1.2.3

**Date:** 2026-07-10

This patch release improves backup reliability, runtime security, and deployment safety.

## Highlights

* Fixed heartbeat handling so HTTP error responses are now treated as failures instead of being silently accepted.
* Fixed the scheduler runtime path by restoring the missing `BackupEngine` import used by scheduled jobs.
* Removed the weak `admin/admin` fallback and now redirects incomplete Web UI credential setups back to the setup wizard.
* Hardened 7z archive creation by sending the backup password through `stdin` instead of exposing it in the process command line.
* Added the new `VERIFY_SSL` setting for Portainer, Gotify, heartbeat, and healthcheck requests, with support in both Setup and Settings screens.
* Added targeted unit coverage and successful runtime smoke tests for container image build, 7z archive creation, and Streamlit health startup.
